# Canvas Study

An installable copy of Canvas's complete light/dark design, with its own example
identity. Install `shellcanvas.theme.json` from Desktop settings, or edit it in a
text editor and use a new ID/name/author before sharing.

To distribute from your own GitHub repository, place `shellcanvas.theme.json` at
the repository root. Users can enter that repository in Settings → Desktop →
Install from GitHub. No build step or SDK is needed.

See [the theme authoring guide](../../../docs/themes.md) and
[schema](../../../docs/schemas/theme.schema.json).
